# VPD-SMART Documentation

This directory contains comprehensive documentation for VPD-SMART metadata packages, including data dictionaries, user manuals, and implementation guides.

## 📋 Contents

### Data Dictionary
- **VPD-SMART Data Dictionary** (Excel format)
  - Contains complete data element definitions and specifications
  - Available in both **English** and **Spanish** tabs
  - Includes metadata structure, validation rules, and field descriptions
  - Essential reference for implementers and data managers

### User Manuals
- **User Manual 1** - Implementation Guide (Spanish)
- **User Manual 2** - System Administration Guide (Spanish)

> **Note**: User manuals are currently available in Spanish only. English translations are in progress and will be available soon.

3. **Implementation Support**: Contact the PAHO technical team for additional guidance
